# Sweet Home 3D Maintenance Lab

A CSC207 maintenance exercise based on Sweet Home 3D 5.4. This fork adds editable furniture descriptions, a sortable volume column, and printing for all viewable levels with the original level restored afterward.

- `SweetHome3D/src/` contains the model, Swing UI, and controllers.
- `assignment-tests/` contains the build smoke test and feature tests.
- `submissions/` contains screenshots and a sample printout.

See the [quick start](QUICK_START.md) for setup and the [assignment](ASSIGNMENT.md) for requirements. Run `mvn -B -ntp clean verify` from the repository root.
